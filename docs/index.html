Core Patterns

See the patterns deep dive and ADRs for details.

Cross-Aggregate Coordination

Domain events coordinate state across aggregates within ACID transactions. See ADR-001.

Optimistic Concurrency

SQL Server RowVersion prevents lost updates on concurrent writes. See ADR-002.

Domain vs Integration Events

Clear separation between transactional and async side effects. See ADR-003.

Structured Error Management

Result pattern with exportable error codes for frontend localization. See ADR-005.

Quick Start

Run the full stack with Docker in two commands.

Terminal 
git clone https://github.com/mohd2sh/CleanArchitecture-DDD-CQRS.git
cd CleanArchitecture-DDD-CQRS
docker-compose up

Includes: SQL Server 2022, API service, automatic migrations and seeding.

Local dev: dotnet run --project src/CleanArchitecture.Cmms.Api

Prerequisites: .NET 8 SDK, Docker Desktop (recommended)
